# JGB37-520 56:1 减速比计算说明

## 1. 电机参数

本文档对应参数标签为 `DC12V 178RPM` 的 JGB37-520 减速电机。

根据 12V 参数表：

| 项目 | 数值 |
|---|---:|
| 减速比 | 1:56 |
| 空载转速 | 178 RPM |
| 额定转速 | 140 RPM |
| 额定转矩 | 6.5 kg·cm |
| 额定电流 | <= 1 A |
| 最大转矩 | 9.0 kg·cm |
| 堵转电流 | 2.3 A |

同一系列中，`12V 333RPM` 才对应 `1:30` 减速比。因此 178 RPM 版本不能使用 30:1 参数。

## 2. 当前编码器参数

当前程序使用的参数如下：

```text
编码器倍频 multiple = 4
编码器线数 PPR       = 11
减速比 ratio         = 56
速度计算周期 T       = 50 ms
车轮半径 r           = 0.065 m
车轮直径 D           = 0.130 m
```

输出轴转一圈对应的编码器计数为：

```text
每圈计数 = multiple * ratio * PPR
每圈计数 = 4 * 56 * 11
每圈计数 = 2464
```

## 3. 编码器计数换算为车轮 RPM

当前控制周期为 50 ms，因此每秒包含：

```text
1000 / 50 = 20 个控制周期
```

每分钟包含：

```text
20 * 60 = 1200 个控制周期
```

车轮转速计算公式为：

```text
车轮 RPM = 计数增量 / (4 * 11 * 56) * (1000 / 50) * 60
```

化简后：

```text
车轮 RPM = 计数增量 / 2464 * 1200
```

```text
车轮 RPM = 计数增量 * 0.487012987
```

例如，一个 50 ms 周期内编码器增加了 349 个计数：

```text
349 / 2464 * 1200 = 170 RPM
```

所以该周期对应的真实车轮转速约为 170 RPM。

## 4. 目标 RPM 换算为编码器计数

由 RPM 反算 50 ms 周期内应产生的计数：

```text
计数增量 = 目标 RPM * 2464 / 1200
```

```text
计数增量 = 目标 RPM * 2.053333
```

当前速度档位对应值如下：

| 档位 | 目标 RPM | 50 ms 理论计数 |
|---|---:|---:|
| G1 | 30 | 约 62 |
| G2 | 55 | 约 113 |
| G3 | 80 | 约 164 |
| G4 | 105 | 约 216 |
| G5 | 130 | 约 267 |
| G6 | 170 | 约 349 |

实际整数计数会因 50 ms 周期内的量化误差产生少量波动。

## 5. 错误使用 30:1 的影响

如果错误使用 30:1，则每圈计数变为：

```text
4 * 30 * 11 = 1320
```

错误 RPM 公式为：

```text
错误 RPM = 计数增量 / 1320 * 1200
```

```text
错误 RPM = 计数增量 * 0.909090909
```

正确 RPM 与错误 RPM 的比例为：

```text
0.909090909 / 0.487012987 = 1.866666
```

也就是错误显示的 RPM 会被放大 `1.8667` 倍。

原来代码认为达到 G6 的 170 RPM 时，50 ms 计数约为：

```text
170 / 0.90909 = 187
```

但这 187 个计数对应的真实车轮转速是：

```text
187 * 0.487012987 = 91 RPM
```

因此，错误配置下代码显示 170 RPM 时，车轮真实速度只有约 91 RPM。

## 6. PWM、电压和转速的关系

不考虑摩擦、负载和电池压降时，电机平均电压与 PWM 占空比的关系为：

```text
电机平均电压 = 电池电压 * PWM 占空比
```

12V 电机空载转速为 178 RPM，因此：

```text
空载转速 = 178 * 电机平均电压 / 12
```

如果电池电压为 12V：

```text
100% 占空比平均电压 = 12V
100% 占空比空载转速 = 178 RPM
```

要达到真实 170 RPM：

```text
所需占空比 = 170 / 178 = 0.955 = 95.5%
```

对应平均电机电压：

```text
12 * 0.955 = 11.46V
```

因此修正为 56:1 后，G6 的 170 RPM 会接近 12V，接近 PWM 100%，而不是错误配置时的约 5~6V。

## 7. 车轮线速度计算

车轮周长为：

```text
车轮周长 = PI * 车轮直径
车轮周长 = 3.14159265 * 0.130
车轮周长 = 0.408407 m
```

单个编码器计数对应的距离为：

```text
单计数距离 = 0.408407 / 2464
单计数距离 = 0.00016575 m
```

车轮线速度为：

```text
线速度 = 车轮 RPM / 60 * 车轮周长
```

例如：

```text
170 RPM = 170 / 60 * 0.408407 = 1.157 m/s
91 RPM  = 91 / 60 * 0.408407 = 0.619 m/s
```

## 8. 当前代码配置

当前减速比定义：

```c
#define ENCODER_REDUCTION_RATIO 56.0f
```

对应的编码器参数：

```c
#define ENCODER_MULTIPLE        4U
#define ENCODER_REDUCTION_RATIO 56.0f
#define ENCODER_PPR             11U
#define ENCODER_WHEEL_RADIUS_M  0.065f
```

修改减速比后，速度闭环和 RPM 遥测会按照真实车轮转速工作。相同的 G1~G6 目标值会比错误配置时快约 `1.8667` 倍，因此需要重新进行实车循迹验证。
