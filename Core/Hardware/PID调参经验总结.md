# BlueCar SpeedPID 调参经验总结（详细版）

## 一、硬件背景

| 组件 | 型号/参数 | 影响 |
|------|----------|------|
| 电机驱动 | TB6612 双路 H 桥 | 单通道刹车会通过机械耦合干扰另一通道 |
| 电机+编码器 | JGB37-520, 30:1 减速, 11 PPR, 4 倍频 | 编码器分辨率 ~88 脉冲/50ms@80RPM, ±3 噪声 |
| 双轮结构 | 差速器 + 齿轮箱 | 机械耦合强，必须双轮同驱 |
| 主控 | STM32F103ZET6, 72MHz | TIM6 ISR 每 50ms 跑一次 PID |

## 二、PID 算法结构

```
位置式 PID: Out = Kp·e(k) + Ki·Σe + Kd·[Actual(k-1)-Actual(k)] + Kf·Target
                └─ P项 ─┘  └─ I项 ─┘  └────── D项(微分先行) ──────┘  └── 前馈 ──┘

附加: Deadband(积分死区) → IntegralLimit(积分限幅) → OutOffset(死区补偿)
     → OutputRateLimit(变化率限制) → OutMax/OutMin(输出限幅)
```

## 三、最终参数及推导

### 3.1 SpeedPID（速度环 — PI）

| 参数 | 最终值 | 推导过程 |
|------|--------|---------|
| **Kp** | 0.35 | 从 0.40 降下来。Kp>0.4 时左轮 RPM 震荡 ±5。JGB37-520 响应快（50ms RPM 可跳 200），Kp 不能大 |
| **Ki** | 0.08 | 从 0.06 升上来。0.06 消静差太慢，0.10 配合小 Deadband 易振荡 |
| **Kd** | 0 | 编码器噪声 ±3 RPM。`DOut = -Kd×(Actual-Actual1)`，对噪声求导→PWM 高频抖动。除非信号干净（如 AHRS 角度），否则绝对不启用 D |
| **Kf L** | 0.69 | 实测 PWM÷RPM 约为 0.75~0.80，取 85% = 0.64~0.68。左轮机械效率略低，给 0.69 |
| **Kf R** | 0.65 | 右轮效率高，0.65。差值 0.04 覆盖了 2~3% 的机械差异 |
| **Deadband** | 1.5 | 关键参数！编码器噪声 ±3 RPM（霍尔传感器 11 线×4 倍频×30 减速比的量化噪声+抖动）。Deadband=1.5 刚好卡在噪声和真误差之间。设 0.5 时积分被噪声推着以 7s 周期振荡；设 3.0 时 2 RPM 真静差消不掉 |
| **IntegralLimit** | 40 | = Kf·Target 缺口的 1.5 倍。Target=140 时 Kf 贡献 0.69×140=96.6，缺口 ~43。堵转时积分不超 40，松手后不会冲 |
| **OutputRateLimit** | 35 | 每 50ms 变 ±35%，0→100% 需 ~150ms。太快伤齿轮，太慢刹车迟钝 |
| **OutMax/Min** | ±100 | PWM 物理上限 |

## 四、关键决策及原理

### 4.1 为什么是 PI 而不是 PID？

**D 项公式**：`DOut = -Kd × (Actual - Actual1)`

这是对**测量值**求导（微分先行），不是对误差求导。编码器在 80 RPM 时每 50ms 的脉冲数约 88，霍尔传感器的电气噪声 ±3 个脉冲 = ±3 RPM。对 ±3 的噪声求导 = 把噪声放大 → 电机 PWM 高频抖动 → 齿轮敲击磨损。

**什么时候能开 D？** 信号必须经过低通滤波且干净。比如 YawPID 的 AHRS 角度——四元数融合本身就是低通，D 项可以安全使用。

### 4.2 Deadband 怎么设？

编码器原始噪声峰值 ±3 RPM。Deadband 的逻辑：

```
if (|误差| > Deadband)  积分累加  // 真误差存在，积分干活
else                   积分冻结  // 死区内，应该是噪声
```

| Deadband | 效果 |
|----------|------|
| 0.3（原始） | 噪声远大于死区，积分永远在动 |
| 0.5 | 噪声偶尔推得动，左轮 7s 周期 ±3% PWM 振荡 |
| 1.5 ✅ | 噪声一半推不动，真误差 >2 RPM 时才激活。PWM 峰峰 ~0.5% |
| 2.0 | 噪声完全推不动，PWM 峰峰 0.2%。但 1~2 RPM 真实静差也被冻住 |
| 3.0 | 太宽，2~3 RPM 静差长期存在 |

**结论**：Deadband ≈ 编码器噪声的 50%~60% 处最平衡。噪声 ±3 → Deadband 1.5~2.0。

### 4.3 Kf 怎么定？

**错误做法**：`Kf = PWM ÷ RPM`（用一次稳态数据直接反算）

问题：电机效率随速度变化。80 RPM 时 PWM/RPM ≈ 0.75，55 RPM 时 ≈ 0.70。用 80 RPM 数据定 Kf=0.75，跑 55 RPM 时就偏了。

**正确做法**：
1. 跑 3 个速度点（30、80、120）
2. 记录稳态 PWM
3. Kf = 各速度点 PWM÷RPM 的**最小值 × 85%**
4. 剩余 15% 由 I 项自适应补偿

本次 Kf_L=0.69 的推导：实测 30 RPM→PWM 25, 80 RPM→PWM 60, 120 RPM→PWM 95。PWM÷RPM 分别是 0.83/0.75/0.79。最小值 0.75×85%≈0.64，加上左轮机械偏差 0.04≈0.68，取 0.69。

### 4.4 单轮调参为什么失败？

TB6612 真值表（IN1/IN2→OUT1/OUT2）：

| IN1 | IN2 | PWM | 状态 |
|-----|-----|-----|------|
| H | L | >0% | 正转 |
| L | H | >0% | 反转 |
| H | L | 0% | **短路刹车** ← 这就是问题！ |
| L | L | X | 浮空 |

给 Motor_SetSpeedA(0) → 进"短路刹车"→ A 电机被锁死 → 机械耦合拖住 B 电机 → B 反转发力不够，正转刹不住。PWM_SET 双轮同驱时两个电机一起动，不存在这个问题。

**解决**：左右轮各一个独立 PID，双轮同步控制。没有"单轮"的概念。

### 4.5 零帧/断点的根因排查

```
现象：VOFA 数据中间隔出现 target=0, pwm=0 的帧
怀疑1：蓝牙噪声干扰 → 加了 return 屏蔽 → 零帧还在
怀疑2：校准按键残留 → 加了按键冲洗 → 零帧还在
怀疑3：无线 DAP 串口丢包 → 用户反馈"问题更严重了"
根因：USART2 (蓝牙) RX 引脚浮空，接收噪声触发 BlueSerial 解析，
      噪声数据被误认为 [joystick,0,0,0,0] → CMD_STOP
```

**教训**：先查硬件（万用表量 RX 脚电平、示波器看波形），不要上来就改代码。两个小时的代码兜圈，罪魁祸首是硬件。

## 五、实战数据对比

### 5.1 Deadband 对 PWM 平滑度的影响

| Deadband | PWM 均值 | PWM 峰峰值 | RPM 波动 | 评价 |
|----------|---------|-----------|---------|------|
| 0.5 | 51.8/52.7 | **±1.0%** | ±1.5 RPM | 积分被噪声推着跑 |
| 1.5 | 57.8/59.2 | **±0.5%** | ±0.7 RPM | ✅ 最佳平衡 |
| 2.0 | 57.7/59.2 | **±0.1%** | ±0.5 RPM | PWM 最平但 RPM 微偏高 |

### 5.2 Kf 调整对 RPM 精度的影响

| Kf L/R | 实测 RPM (Target=80) | 稳态偏差 |
|--------|---------------------|---------|
| 0.65/0.65 | 78~82 | +0~2 |
| 0.55/0.55 | 76~79 | -1~-4 |
| 0.69/0.65 | **80.0~81.5** | **+0~1.5** ✅ |
| 0.73/0.72 | 80.9~81.8 | +1~2 |

### 5.3 完整稳态波形特征

```
好的波形（Deadband=1.5, Kf=0.69/0.65）:
  PWM: ──────────── (平，±0.5%)  
  RPM: ~ ~ ~ ~ ~ ~  (编码器噪声，±1 RPM)

差的波形（Deadband=0.5）:
  PWM: /\/\/\/\/\/\ (周期摆动，±1.5%)
  RPM: ≈≈≈≈≈≈≈≈≈≈ (跟踪摆动)
```

## 六、调参操作清单（按顺序）

| 步骤 | 操作 | 判据 |
|------|------|------|
| 1 | 设 Deadband=3.0, Kf=0.5, Kp=0.3, Ki=0.05 | 安全起步 |
| 2 | 跑 3 个速度点，记录稳态 PWM | 30/80/120 RPM |
| 3 | Kf = min(PWM÷RPM) × 0.85 | 覆盖 85% 稳态需求 |
| 4 | 看阶跃响应，超调 >10% 就降 Kp | 每次降 0.05 |
| 5 | 有稳态静差 >3 RPM 就加 Ki | 每次加 0.02 |
| 6 | Deadband 收到 PWM 峰峰 <1% | 不要低于编码器噪声的 50% |
| 7 | 变化率限制设到 ~150ms 满占空 | 太快伤齿轮，太慢刹车迟钝 |
| 8 | 串口 skfl/skfr 微调左右 Kf 差 | 对齐左右 PWM 均值 |
| 9 | commit 保存 | 调好了就别动了 |
