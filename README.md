# BlueCar STM32F103 循迹小车

本工程基于 STM32F103ZET6 和 STM32 HAL，实现八路数字循迹、蓝牙手动控制、
双轮独立增量式速度闭环、直行航向修正、OLED 状态显示和 VOFA+ 遥测。

本文只记录当前源码能够确认的参数和控制思想。电机参数以实测使用的
JGB37-520 12 V、178 RPM、1:56 减速版本和 11 PPR 编码器为准。

## 3. 电机与编码器参数

JGB37-520 的 DC12V 测试规格如下。

| 参数 | 数值 |
| --- | --- |
| 减速比 | 1:56 |
| 空载转速 | 178 RPM |
| 空载电流 | 不大于 120 mA |
| 额定转速 | 140 RPM |
| 额定转矩 | 6.5 kg·cm |
| 额定电流 | 不大于 1 A |
| 最大转矩 | 9.0 kg·cm |
| 堵转电流 | 2.3 A |

编码器每个电机轴圈有 11 个脉冲。经过 1:56 减速箱和四倍频解码后，
输出轴每转计数为：

```text
counts_per_output_revolution = 4 * 56 * 11 = 2464
```

50 ms 控制周期的转速换算为：

```text
RPM = count * 1200 / 2464
RPM = count * 0.487012987
count = RPM * 2.053333
```

车轮半径为 `0.065 m`，因此轮胎周长为 `0.408407 m`，一个输出轴计数对应
约 `0.00016575 m` 的行驶距离。

## 4. 控制架构

### 4.1 周期任务

| 周期 | 任务 | 主要工作 |
| --- | --- | --- |
| 1 ms | TIM5 | 递增 `milliseconds` 系统时间 |
| 10 ms | 传感器任务 | 读取 MPU6050 异步结果并更新姿态 |
| 20 ms | 键扫任务 | 运行非阻塞按键状态机 |
| 20 ms | 循迹任务 | 采样八路红外、查表和急弯状态机 |
| 50 ms | 控制任务 | 编码器测速、命令执行、速度环、堵转保护 |
| 50 ms | 遥测任务 | 生成并发送 VOFA CSV |
| 100 ms | 显示任务 | 在 OLED 上刷新当前模式状态 |
| 主循环 | 串口、蓝牙 | 解析调参响应、命令帧和待执行命令 |

### 4.2 命令队列

按键、蓝牙以及 USART1 的速度、转向、启停命令统一生成 `commandMessage_t`，
写入 8 项环形命令队列，再由 50 ms 控制任务集中执行；队列满时丢弃新命令，
不覆盖尚未执行的控制动作。

USART1 在线调参的 `skp/ski/skd`、`lkp/lki/lkd`、`rkp/rki/rkd` 和
`ykp/yki/ykd/ykf` 会直接修改对应 PID 的内存参数，`duty` 会直接修改开环 PWM
测试值，不经过命令队列。这类直接修改只在本次上电期间有效。

### 4.3 八路数字循迹

- 八路原始输入由普通 GPIO 数字采样，并归一化为统一逻辑：`raw=0` 表示黑线，
  `raw=1` 表示白线。
- `pattern` 的 bit0-bit7 分别对应 IR1-IR8，黑线通道置 1。
- 256 项查表将图案映射为归一化位置和左右轮百分比。
- 窄线位置使用 0.55/0.45 一阶低通，减小单通道切换造成的抖动。
- 普通循迹最低前进目标为 15 RPM，不依赖内轮反转。
- 丢线后按左右方向交替扫线，外轮 35 RPM、内轮 10 RPM，不反向寻线。
- 边缘候选持续约 100 ms；单侧至少 3 路压线且比另一侧至少多 2 路时可直接
  触发急弯，全部丢线时也可使用仍在保持期的边缘候选方向触发。
- 急弯输出为外侧轮 `+50 RPM`、内侧轮 `-50 RPM`，最短运行 120 ms。
- 转弯过程中 IR4/IR5 任一路压线且 `abs(position) <= 2.0` 连续确认 3 个
  20 ms 周期时，可以提前结束并回到普通循迹。
- 编码器左右累计计数差达到 4000 时先进入 `REACQUIRE`，以左右轮各 15 RPM
  低速前进找线；该 4000 是实车标定阈值，不能仅凭源码换算为精确九十度。
- 重捕期间中线连续确认 3 个周期后回到 `FOLLOW`；确认到下一弯并保持 2 个
  周期时直接启动下一次转向；1 秒内仍未居中则进入丢线搜索。
- 急弯动作超过 2 秒仍未达到编码器阈值时进入丢线搜索。
- 八路全黑连续确认后计圈；八路全白进入丢线搜索。

实际急弯状态流为：

```text
FOLLOW -> TURN_LEFT/TURN_RIGHT -> REACQUIRE -> FOLLOW
                                      |            ^
                                      +-> 下一次转向
                                      |
                                      +-> LOST（重捕超时）
```

### 4.4 双轮速度环

左右轮各自运行一个 50 ms 增量式速度环，默认参数为：

```text
Kp = 0.25
Ki = 0.020
Kd = 0
```

增量式速度环只使用 `Kp`、`Ki`、`Kd`，不使用前馈。速度反馈先进行三点
中值滤波，再进行 0.75/0.25 一阶低通。输出限制为 `-100%...+100%`，
误差死区为 1.8 RPM，单周期输出变化限制为 35 个百分点。
当左右目标转速发生正负反号时，速度环会清除旧方向输出和误差历史，避免
内侧轮保留转弯前的正 PWM；反转周期立即按负目标重新建立输出。

当目标低于 20 RPM 时，如果 PID 输出方向和目标一致但绝对值低于 12%，
会施加 12% 的低速补偿，以克服电机和减速箱静摩擦。

### 4.5 直行航向修正

手动直行时，MPU6050 航向角环每 100 ms 更新一次，默认参数为：

```text
Kp = 2.0
Ki = 0.02
Kd = 0.5
```

航向环输出限制为 `-10...+10 RPM`，积分限幅为 10，误差死区为 0.5 度，
单次输出变化限制为 2 RPM。航向修正量以左右各一半的方式叠加到基础目标，
随后仍由左右独立速度环跟踪。

### 4.6 堵转保护

同时满足以下条件并连续保持 25 个 50 ms 周期、约 1.25 秒后，停车保护：

- 目标转速绝对值大于 20 RPM。
- 编码器实际转速绝对值小于 2 RPM。
- PWM 输出绝对值大于 25%。

进入保护后清空目标、PID 历史、滤波器和循迹状态，并立即关闭电机。

## 5. 当前运行配置

### 5.1 PWM

| 项目 | 参数 |
| --- | --- |
| 定时器 | TIM1 |
| 预分频 | 0 |
| 自动重装载值 | 4499，即配置值 `MOTOR_PWM_PERIOD - 1` |

TIM1_CH1 驱动 B 轮，TIM1_CH2 驱动 A 轮。方向控制由 PF1-PF4 完成。

| 档位 | 目标速度 |

| G5 | 130 RPM |

## 6. 通信

### 6.1 调试和调参

USART1 使用 PA9/PA10、115200 bps、8N1：

- TX 使用 `HAL_UART_Transmit_IT`，中断完成后从发送环形缓冲区继续发送。
- RX 使用单字节中断接收，中断只缓存数据。
- 命令行在主循环解析，电机控制命令进入统一命令队列。
- VOFA CSV 和文本调参响应共用 USART1。

### 6.2 蓝牙协议

USART2 使用 PA2/PA3、9600 bps。协议帧格式如下：

```text
[joystick,<left_horizontal>,<left_vertical>,<right_horizontal>,<right_vertical>]
[key,<number>,<up/down>]
```

按键帧支持启动、停止和换档。摇杆纵向值控制基础速度，右摇杆横向值控制
差速；右摇杆横向绝对值达到 80% 时使用一正一反原地转。

## 7. 在线调参命令

命令通过 USART1 输入，以回车或换行结束。

| 命令 | 作用 |
| --- | --- |
| `skp N`、`ski N`、`skd N` | 同时设置左右增量速度环参数 |
| `lkp N`、`lki N`、`lkd N` | 设置左轮增量速度环参数 |
| `rkp N`、`rki N`、`rkd N` | 设置右轮增量速度环参数 |
| `ykp N`、`yki N`、`ykd N`、`ykf N` | 设置航向角环参数 |
| `t N`、`tl N`、`tr N` | 设置双侧或单侧速度目标 |
| `turn N` | 设置左右差速量 |
| `pivot N` | 设置一正一反原地转速度 |
| `yaw N` | 设置航向角目标 |
| `start`、`stop` | 启动或停止 |
| `duty N` | 进入 PWM 开环测试并设置占空比 |
| `quiet`、`log` | 暂停或恢复 VOFA 输出 |
| `yaw0` | 将当前航向角设为零点 |
| `show` | 显示 PID、目标和运行状态 |
| `help` 或 `?` | 显示命令列表 |

参数命令立即修改内存中的 PID 参数，但不会持久化到 Flash。重新上电后恢复
源码中的默认值。

## 8. VOFA+ 遥测

控制任务每 50 ms 更新遥测快照，并发送 12 个逗号分隔字段：

```text
tgtRpmL,rpmFL,rpmL,tgtRpmR,rpmFR,rpmR,steerRpm,diffRpm,yawDeg,mode,run,gear
```

| 字段 | 单位 | 含义 |
| --- | --- | --- |
| `tgtRpmL` | RPM | 左轮目标速度 |
| `rpmFL` | RPM | 左轮滤波后速度 |
| `rpmL` | RPM | 左轮编码器速度 |
| `tgtRpmR` | RPM | 右轮目标速度 |
| `rpmFR` | RPM | 右轮滤波后速度 |
| `rpmR` | RPM | 右轮编码器速度 |
| `steerRpm` | RPM | 循迹差速或航向修正量 |
| `diffRpm` | RPM | 左轮减右轮的实际速度差 |
| `yawDeg` | 度 | 航向角 |
| `mode` | 枚举值 | 当前工作模式 |
| `run` | 0/1 | 停止或运行 |
| `gear` | 1-6 | 当前速度档位 |

## 9. 构建与调试

### 9.1 Keil MDK

使用 Keil MDK-ARM 打开：

```text
MDK-ARM/bluecar.uvprojx
```

工程目标为 `bluecar`，器件为 `STM32F103ZE`。命令行构建可使用 ARMCC 5.06：

```powershell
UV4.exe -b MDK-ARM\bluecar.uvprojx -j0 -o build.log
```

传统 Keil 构建产物位于 `MDK-ARM/bluecar/`，CMSIS 构建产物位于
`MDK-ARM/build/bluecar/`。

### 9.2 串口调试

1. 将 USART1 的 PA9/PA10 接到 USB 串口工具，使用 115200 bps、8N1。
2. 复位后可看到 `BOOT OK` 和 VOFA CSV 表头。
3. 使用 `help` 查看命令，使用 `show` 查看实时闭环状态。
4. 使用 VOFA+ 按 12 字段顺序配置波形。

### 9.3 实车调参

1. 先架空车轮，用 `duty` 确认两个电机方向和编码器计数方向一致。
2. 用 `t` 或 `tl`、`tr` 在低速下确认轮速换算接近实际转速。
3. 分别整定左右速度环，先调 `Kp`，再加入少量 `Ki`，最后按需加入 `Kd`。
4. 设置相同的左右目标，观察并调整航向环，避免直行时持续偏移。
5. 在低速下验证循迹图案、急弯和丢线恢复，再逐步提高档位。
6. 修改确认后的默认值时，更新 `Core/Application/yingYongZhuangTai.c` 顶部宏。

校正减速比、安装方向或轮径后必须重新验证速度、航向和急弯参数。停车和
模式切换只清除 PID 历史状态，不恢复默认增益；在线修改的 PID 参数会一直
保留到重新上电，因此正式参数需要写回源码默认宏。
